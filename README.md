# Neurotech Pulse

A curated, Claude-authored newsletter on **applied neurotechnology** — the companies, products, clinical deployments, and the AI and data science underneath. AI in neurotech is the lede.

**Live site:** https://bkowshik.github.io/neurotech-pulse/

Three cadences:

- **Daily** — 5-ish items, terse, source-linked.
- **Weekly** — themes, *Frontier Watch*, what I'm watching next.
- **Monthly** — top 10, deep dive (rotating: Frontier Model Spotlight / Company Spotlight / Paper-to-Production), UK Jobs & Funding.

## How it works

- [`REQUIREMENTS.md`](./REQUIREMENTS.md) — scope, audience, priorities, success criteria.
- [`CLAUDE.md`](./CLAUDE.md) — the operating brief Claude follows when generating posts.
- [`SOURCES.md`](./SOURCES.md) — canonical, editable source list, organised by priority thread.

Posts live under `daily/`, `weekly/`, `monthly/` (one directory per post). Built with [Quarto](https://quarto.org), deployed to GitHub Pages on push to `main`.

## Editorial bar

Primary sources only. Preprints flagged. No invented quotes, statistics, or URLs. If a day doesn't have enough verifiable material, no post goes out.
